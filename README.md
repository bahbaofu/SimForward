# SimForward

把某張 SIM 收到的短信，轉發到另一個號碼（短信接口）和/或郵箱（郵件接口）。
無第三方依賴；郵件用內建的極簡 SMTP 客戶端（SSL/STARTTLS，驗證憑證主機名）。

## 在 Mac 上建置
1. Android Studio → File → Open 選本資料夾，等 Gradle Sync。
2. Pixel 6 開啟開發人員選項與 USB 偵錯，接上 USB。
3. 按 Run ▶ 安裝（或 Build APK 後 `adb install`）。用 adb/Android Studio 安裝可避開「受限制設定」。

## 郵件設定範例
- Gmail：smtp.gmail.com，埠 465，帳號為完整 Gmail，密碼用「應用程式密碼」（需先開兩步驟驗證）。
- 其他郵箱：用服務商提供的 SMTP 位址與「授權碼 / 應用程式專用密碼」，不要用登入主密碼。

## 隱私提醒
- 郵件接口需要 INTERNET 權限，短信內容（含驗證碼）會經過你的郵件服務商。
- SMTP 密碼存在 App 私有儲存區（明文），所以請務必用專用密碼，而非主密碼。
- 若只用短信接口，可在系統設定把本 App 的「網絡」權限關閉。

## 重試機制
所有轉發任務先寫入發件匣（Outbox），成功後才刪除。失敗時以 1、2、4、8…分鐘（最長 1 小時）間隔重試，
最多 8 次，重開機後仍保留。短信以系統回報的「已交給網絡」為成功；5 分鐘內沒有回報視為失敗並重送
（因此極少數情況下可能收到重複短信，這是「寧可重複、不可漏收」的取捨）。
發件匣內的短信全文只在尚未成功送出時暫存於 App 私有儲存區。

## Gmail
帳號填完整 Gmail 地址，密碼填「應用程式密碼」（Google 帳戶 → 安全性 → 兩步驟驗證 → 應用程式密碼）。
